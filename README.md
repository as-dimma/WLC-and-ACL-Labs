# WLC and ACL Labs

A collection of hands-on networking labs documenting my journey towards mastering **Wireless LAN Controllers (WLCs)** and **Access Control Lists (ACLs)** using Cisco Packet Tracer.

## About This Repository

This repository contains practical exercises designed to strengthen my understanding of wireless networking, network access control, and their implementation in Cisco environments.

Rather than documenting only successful configurations, I also share the challenges I encounter, troubleshooting processes, mistakes, and lessons learned throughout each lab.

## Repository Structure

Each lab is organised into its own directory containing:

- **README.md:** Lab documentation, implementation process, challenges, troubleshooting, and key takeaways.
- **Context:** The scenario, requirements, and objectives of the lab.
- **Packet Tracer File:** The `.pkt` project file.
- **Screenshots:** Visual documentation of configurations and verification.
- **Topology:** A visual representation of the network design.

## Topics Covered

- Wireless LAN Controller configuration
- Lightweight Access Point registration
- SSID configuration and wireless security
- Wireless network integration with VLANs
- Access Control Lists (ACLs)
- Network access control and traffic filtering
- Troubleshooting and verification

*Topics will be added as I progress.*

## Tools and Technologies

- Cisco Packet Tracer
- Cisco Wireless LAN Controller (WLC-PT)
- Cisco routers and switches
- Markdown and GitHub

## Learning Approach

Each lab documents:

1. The problem or scenario being addressed.
2. The objectives and expected outcomes.
3. Network design and implementation.
4. Configuration and verification.
5. Challenges and troubleshooting.
6. Key lessons learned.
